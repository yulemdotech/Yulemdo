# Contributing to Yulemdo

Yulemdo — O‘zbekistonda yaratilayotgan ochiq va mustaqil raqamli ekotizim. Loyiha hali faol rivojlanish bosqichida, shuning uchun fikrlar, takliflar va kichik tuzatishlar ham muhim.

## Qanday hissa qo‘shish mumkin?

- Xatolik haqida issue ochish
- Yangi imkoniyat taklif qilish
- Hujjatlarni yaxshilash
- O‘zbek tilidagi matnlarni tahrirlash
- Kod, test yoki misol loyiha qo‘shish

## Pull request jarayoni

1. Repository’ni fork qiling va yangi branch yarating:
   ```bash
   git checkout -b feature/qisqa-nom
   ```
2. O‘zgarishingizni kichik va aniq commitlarga ajrating.
3. Testlar mavjud bo‘lsa, ularni ishga tushiring.
4. Pull request ochib, o‘zgarish maqsadini va tekshirish qadamlarini yozing.

## Commit xabarlari

Commit xabarlarini qisqa va mazmunli yozing. Masalan:

- `docs: contribute guide qo‘shildi`
- `feat: search API uchun misol qo‘shildi`
- `fix: README havolasi tuzatildi`

## Til va uslub

Foydalanuvchi ko‘radigan matnlarda sodda, tushunarli o‘zbek tilidan foydalaning. Texnik nomlar uchun umumiy qabul qilingan inglizcha atamalarni qavs ichida berish mumkin.

## Savollar

Noaniq masalalarda avval issue oching — qarorlar ochiq muhokama qilinishi va keyinchalik hujjatlashtirilishi kerak.
